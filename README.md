# رفقا لایو (Friends Status Live)

اپ اندرویدی برای اینکه با یه لمس به رفقات بگی الان داری چی‌کار می‌کنی. پیاده‌سازی طراحی «App Screens v2» از Claude Design با Kotlin و Jetpack Compose.

## وضعیت فعلی

- **کل رابط کاربری** طراحی پیاده شده: آنبوردینگ، صفحه‌ی رفقا (همه‌ی گروه‌ها و حالت دونفره)، انتخاب وضعیت (با وضعیت‌های خصوصی و دکمه‌ی اضطراری)، جزئیات رفیق، حریم خصوصی، تنظیمات گروه (منوی عضو، حذف عضو، برگه‌ی دعوت با QR واقعی)، پروفایل، ویرایشگر کاراکتر و برش عکس.
- **فقط فارسی و راست‌به‌چپ**، با فونت‌های وزیرمتن و لاله‌زار.
- **تم تیره و روشن** بر اساس تنظیمات گوشی.
- **تغییرها نسبت به طراحی:** بخش نقشه و انتخاب پسر/دختر حذف شده‌اند؛ همه با یک مجموعه‌ی کاراکتر نشون داده می‌شن و همه‌ی وضعیت‌ها و وسایل در دسترس همه‌ست.
- **داده‌ها نمونه‌اند:** دوستان، گروه‌ها و دعوت‌ها فعلاً داخل حافظه‌ی گوشی ساخته می‌شن (`data/FakeData.kt`) و وضعیت رفقا هر چند ثانیه خودکار عوض می‌شه تا حس «زنده» رو نشون بده. تنظیمات خودت (اسم، کاراکتر، محبوب‌ها، حالت روح و…) و عکس پروفایل روی گوشی ذخیره می‌شن.

## ساخت و اجرا

- **Android Studio:** پوشه‌ی پروژه رو باز کن و `app` رو اجرا کن.
- **خط فرمان:** `./gradlew assembleDebug` فایل `app/build/outputs/apk/debug/app-debug.apk` رو می‌سازه.
- **GitHub Actions:** با هر push، فایل APK ساخته می‌شه و در بخش Artifacts همون اجرا (`app-debug`) قابل دانلوده.

حداقل اندروید ۸ (API 26).

## ساختار کد

| مسیر | محتوا |
|---|---|
| `model/` | مدل‌ها، فهرست وضعیت‌ها و گروه‌ها (`Catalog.kt`)، اعداد فارسی (`Fa.kt`) |
| `data/AppStore.kt` | کل وضعیت اپ و همه‌ی کارها (ارسال وضعیت، مدیریت گروه، …) |
| `data/Platform.kt` | کارهایی که فقط اندروید انجام می‌ده (کلیپ‌بورد، اشتراک، انتخاب عکس، مجوز مکان) |
| `ui/screens/` | صفحه‌ها |
| `ui/components/` | کاراکترها، دکمه‌ها، برگه‌ها، QR و اجزای مشترک |
| `MainActivity.kt` | نسخه‌ی اندرویدی `Platform` و اتصال به سیستم |
| `tools/characters/` | اسکریپت ساخت تصویر کاراکترها از فایل‌های طراحی |

## کاراکترها

کاراکترها در طراحی با SVG و جاوااسکریپت ساخته شده‌اند. برای اندروید، با `tools/characters/render.mjs` به WebP تبدیل شده‌اند (`res/drawable-nodpi`). کاراکتر خودت از چهار لایه (بدن، لباس، صورت، وسیله) روی هم ساخته می‌شه. برای ساخت دوباره:

```sh
cd tools/characters && npm i playwright && node render.mjs ../../app/src/main/res/drawable-nodpi
```

## قدم بعدی: سرور

برای اینکه وضعیت‌ها واقعاً بین گوشی‌ها جابه‌جا بشن، باید یه سرور وصل بشه. کارهای `AppStore` که `friends`، `me` و `admin` رو تغییر می‌دن جاییه که باید به سرور وصل بشن.
