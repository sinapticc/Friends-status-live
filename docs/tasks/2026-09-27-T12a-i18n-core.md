## Mechanism (keep it simple and compile-safe)
1. New file `model/L10n.kt` (shared, platform-neutral):
   ```kotlin
   object L10n { var isFa: Boolean = true }
   fun t(fa: String, en: String): String = if (L10n.isFa) fa else en
   ```
2. Set it once at startup: Android `MainActivity.onCreate` (before setContent) and also in `android/` entry points used without the activity (widget `provideGlance`, `SyncWorker`, `WidgetConfigActivity`): `L10n.isFa = java.util.Locale.getDefault().language in setOf("fa", "per")`. Desktop preview: `L10n.isFa = System.getProperty("lang", "fa") == "fa"`.
3. `ui/AppRoot.kt`: layout direction = `if (L10n.isFa) Rtl else Ltr` (currently forced RTL). Check the `mirror()`/icon-direction helpers in `ui/components/Common.kt` still point the right way in LTR (back arrow etc.); fix so arrows are correct in both.
4. `model/Fa.kt`: `digits()`/`num()` return Latin digits when `!L10n.isFa`; `code()` keeps LTR isolate. Relative-time strings («۵ دقیقه پیش» etc.) → use `t(...)` with English ("5 min ago", "just now", "yesterday").
5. `app_name` stays «Friends Status Live» in both resource files.
